# Chethan S Portfolio

A responsive Next.js 15 portfolio for Chethan S, designed around networking, troubleshooting, technical support and software development.

## Included
- Networking projects shown first
- Online Airline Reservation System
- Devs Shopping Cart, Investment Calculator and Market Access links
- Four internships from the resume
- Skills and education from the resume
- Uploaded certificates with viewable files
- Resume download
- Responsive 360px mobile layout
- Dark theme, violet accent, subtle network visual and lightweight Framer Motion reveals

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000.
